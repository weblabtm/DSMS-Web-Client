# entities/student

Student entity models and helpers.
Use for learner data, enrollment state, contact information, and progress records.

## API Client

The domain API client for this entity is located at `api/studentApi.js`. It extends [BaseApiClient](file:///c:/Users/sadee/Documents/weblabtm/sadeeshaweblabtm/DSMS-Web-Client/src/shared/api/BaseApiClient.js) and exports a singleton instance (`studentApi`). All API calls relating to this domain should be made using this client.
