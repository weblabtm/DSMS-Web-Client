# entities/instructor

Instructor entity models and helpers.
Use for staff profiles, certifications, assignments, and workload data.

## API Client

The domain API client for this entity is located at `api/instructorApi.js`. It extends [BaseApiClient](file:///c:/Users/sadee/Documents/weblabtm/sadeeshaweblabtm/DSMS-Web-Client/src/shared/api/BaseApiClient.js) and exports a singleton instance (`instructorApi`). All API calls relating to this domain should be made using this client.
