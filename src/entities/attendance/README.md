# entities/attendance

Attendance entity models and helpers.
Use for attendance records, session marks, and compliance history.

## API Client

The domain API client for this entity is located at `api/attendanceApi.js`. It extends [BaseApiClient](file:///c:/Users/sadee/Documents/weblabtm/sadeeshaweblabtm/DSMS-Web-Client/src/shared/api/BaseApiClient.js) and exports a singleton instance (`attendanceApi`). All API calls relating to this domain should be made using this client.
