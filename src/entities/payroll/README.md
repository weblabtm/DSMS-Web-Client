# entities/payroll

Payroll entity models and helpers.
Use for salary records, payouts, deductions, and compensation state.

## API Client

The domain API client for this entity is located at `api/payrollApi.js`. It extends [BaseApiClient](file:///c:/Users/sadee/Documents/weblabtm/sadeeshaweblabtm/DSMS-Web-Client/src/shared/api/BaseApiClient.js) and exports a singleton instance (`payrollApi`). All API calls relating to this domain should be made using this client.
