# entities/report

Report entity models and helpers.
Use for reporting definitions, output payloads, and analytics contracts.

## API Client

The domain API client for this entity is located at `api/reportApi.js`. It extends [BaseApiClient](file:///c:/Users/sadee/Documents/weblabtm/sadeeshaweblabtm/DSMS-Web-Client/src/shared/api/BaseApiClient.js) and exports a singleton instance (`reportApi`). All API calls relating to this domain should be made using this client.
