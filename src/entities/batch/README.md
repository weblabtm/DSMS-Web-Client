# entities/batch

Batch entity models and helpers.
Use for cohort definitions, schedules, capacity, and lifecycle state.

## API Client

The domain API client for this entity is located at `api/batchApi.js`. It extends [BaseApiClient](file:///c:/Users/sadee/Documents/weblabtm/sadeeshaweblabtm/DSMS-Web-Client/src/shared/api/BaseApiClient.js) and exports a singleton instance (`batchApi`). All API calls relating to this domain should be made using this client.
